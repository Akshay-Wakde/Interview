Event Bubbling

In JavaScript, Event Bubbling is a type of event propagation where an event starts from the deepest target element and then "bubbles up" through its ancestors in the DOM tree until it reaches the window object.

1. How it Works: The Propagation Path

When you click a button inside a div, the event doesn't just happen on the button. The browser triggers the event in this order:
  • Button (Target)
  • Div (Parent)
  • Body
  • HTML
  • Document / Window
